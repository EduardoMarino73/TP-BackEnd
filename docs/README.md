# Documentación — CineWeb Backend (TP-BackEnd)

Punto de entrada de la documentación del backend, con lo que pide la cátedra para la entrega de
regularidad (`docs.md` del TP). El frontend tiene su propia documentación en
[cineweb-frontend](https://github.com/liamlucca/cineweb-frontend).

## Regularidad

| Contenido | Dónde está | Estado |
|---|---|---|
| Propuesta actualizada | [proposal.md en el fork del TP](https://github.com/liamlucca/tp-web-de-peliculas/blob/main/proposal.md) | ✅ |
| Links a los PR | [Pull requests](#pull-requests) (abajo) | 🟡 Falta el PR de la propuesta |
| Instrucciones de instalación | [README del proyecto → Quick start](../README.md#quick-start) | ✅ |
| Minutas de reunión y avance | [Registro de avance](avance.md) (armado a partir de git) y [minutas](minutas/README.md) | 🟡 Faltan las minutas |
| Tracking de features, bugs e issues | [tracking.md](tracking.md) | 🟡 Falta el tablero |

`avance.md`, `tracking.md` y `minutas/` son del equipo: están copiados igual en el frontend.
