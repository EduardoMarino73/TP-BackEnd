# Documentation — CineWeb Backend (TP-BackEnd)

Entry point of the backend's documentation, with what the course asks for the regularity delivery
(the course's `docs.md`). The frontend has its own documentation in
[cineweb-frontend](https://github.com/liamlucca/cineweb-frontend).

## Regularity

| Item | Where |
|---|---|
| Updated proposal | [proposal.md in the course fork](https://github.com/liamlucca/tp-web-de-peliculas/blob/main/proposal.md) |
| Links to the PRs | [Pull requests](#pull-requests) (below) |
| Installation instructions | [Project README → Quick start](../README.md#quick-start) |
| Meeting and progress minutes | [Progress minutes](progress.md) (built from the git history) |
| Tracking of features, bugs and issues | [tracking.md](tracking.md) |

`progress.md` and `tracking.md` belong to the team: an identical copy lives in the frontend.
